# desafioDIO-textract
Neste desafio foi pedido para gerar um código em python que imprima o texto extraído de uma imagem com o uso AWS Textract 

Optei em usar o AWS CloudShell ao invés do AWS CLI para a execução do desafio

Documentação 
  https://docs.aws.amazon.com/cloudshell/
  https://docs.aws.amazon.com/pt_br/textract/
